## 1️⃣ What is the difference between var, let, and const?
i. var is function-scoped and can be redeclared and updated. <br>
ii. let is block-scoped and can be updated but not redeclared. <br>
iii. const is block-scoped and cannot be updated or redeclared after assignment.

## 2️⃣ What is the spread operator (...)?
The spread operator example elements of an array or object, allowing them to be copied or combined into another array or object.

## 3️⃣ What is the difference between map(), filter(), and forEach()?
i. map() creates a new array by transforming each elements. <br>
ii. filter() creates a new array with elements that meet a condition.<br>
iii. forEach() runs a function on each elements but does not return a new array.

## 4️⃣ What is an arrow function?
A shorter syntax for writing functions that uses the surrounding context's this. for example: const add = (a,b) => a + b; is an arrow function that returns the sum of two numbers.

## 5️⃣ What are template literals?
String written with backticks(`) that allow embedded expressions using ${} and support multiline text.
